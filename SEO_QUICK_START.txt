Apartment Pros website v0.5 - SEO quick start
=============================================

1) Deploy backend/LocatorBackend-v0.5.gs as the website Apps Script backend.
2) Put the deployed /exec URL in assets/js/config.js.
3) Before publishing the static site, run:

   node tools/build-seo-pages.mjs --root=. --origin=https://www.avreyanderson.com --api=YOUR_APPS_SCRIPT_EXEC_URL

4) Publish the whole folder.
5) Add https://www.avreyanderson.com to Google Search Console.
6) Submit https://www.avreyanderson.com/sitemap.xml.
7) Inspect a city URL and several generated floorplan URLs in Search Console.
8) Re-run the generator whenever inventory is materially updated; nightly is reasonable.

For Cloudflare Pages, the included _headers file adds response security headers.
For GitHub Pages, use the included HTML CSP/referrer policies and put Cloudflare in front
if you need full response-header enforcement.
